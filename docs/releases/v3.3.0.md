# 🚗 VehicleVault v3.3.0 — Reverse Proxy SSO Session Issuance & Architecture Diagnostics

**VehicleVault v3.3.0** introduces end-to-end automatic session issuance for reverse proxies:
- **Pangolin / Authelia / Authentik SSO Auto-Session:** HTTP-only `refresh_token` and `vv_token` cookies are minted on initial page load when trusted proxy headers are present.
- **Root Diagnostic Endpoint (`/proxy-debug`):** Real-time inspection of client IP, proxy headers, and authenticated proxy user status.
- **Security:** Strict IP validation for RFC 1918, CGNAT, Tailscale, and Docker bridge networks.

# 🚗 VehicleVault v3.3.1 — Multi-Tenant Home Assistant Schema & Scoped Ingestion

**VehicleVault v3.3.1** introduces isolated smart home credentials:
- **Per-User Home Assistant Configs (`user_ha_configs`):** Multi-tenant database table storing encrypted tokens and URLs per user account.

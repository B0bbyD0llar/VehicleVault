## 🛡️ Critical Security Hardening

As part of our commitment to privacy and self-hosting security, several high-risk attack surfaces have been proactively eliminated:

1. **Pre-Auth Account Takeover Patched (`/api/auth/forgot-password`):**
   - Fixed an issue where password reset tokens were returned in JSON responses when SMTP was unconfigured. Reset tokens are now strictly delivered via email or logged securely to the server console for homelab admins.
2. **Reverse Proxy SSO IP-Spoofing Bypass Patched (`proxyAuth.ts`):**
   - `proxyAuth` now verifies direct TCP socket peer addresses (`req.socket.remoteAddress`) rather than trusting user-manipulable `X-Forwarded-For` headers.
3. **Driver Document Authorization Patched (BOLA / IDOR in `fileAuth.ts`):**
   - Restricted driver roles from viewing document attachments belonging to unauthorized vehicles.
4. **Arbitrary File Upload & Stored XSS Mitigation (`upload.ts`):**
   - Implemented strict extension and MIME whitelisting for invoice/document uploads, preventing executable files, `.svg`, and `.html` uploads.
